# RoboOps v0.1.0

The first tagged RoboOps portfolio release packages the implemented robotics
fleet operations platform as versioned backend and frontend container images.

## Included

- FastAPI APIs with JWT authentication and viewer/operator/admin RBAC.
- PostgreSQL schema migrations, deterministic synthetic fleet data, and
  idempotent telemetry ingestion.
- Kafka/Redpanda telemetry delivery with bounded retry and DLQ handling.
- React operations dashboard, robot workflows, alert lifecycle, and
  condition/anomaly analytics.
- Unsupervised telemetry condition scoring with explicit training-readiness
  gates; no failure probability, remaining useful life, or model accuracy is
  claimed.
- Prometheus HTTP metrics, request correlation, readiness checks, non-root
  production containers, and Nginx frontend serving.
- PostgreSQL, Kafka, full-stack container, and Chromium browser validation in
  GitHub Actions.

## Published artifacts

- `ghcr.io/kamjula/roboops-backend:0.1.0`
- `ghcr.io/kamjula/roboops-frontend:0.1.0`

Both images are built with SBOM and provenance metadata. Registry visibility
is controlled by the repository owner's GitHub Packages settings.

The frontend image is built for a browser-accessible backend at
`http://localhost:8000`. A hosted environment with a different backend origin
must rebuild it with the appropriate `VITE_API_BASE_URL` build argument.

## Honest scope

RoboOps v0.1.0 is a portfolio release built and tested with synthetic data. It
does not claim a public hosted deployment, production uptime, real customer
traffic, cost savings, business impact, supervised failure-prediction accuracy,
or remaining useful life estimation.
